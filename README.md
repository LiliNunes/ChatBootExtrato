Chatbot Bancário – Regras e NLP

Este projeto foi desenvolvido para a disciplina Chatbots e Assistentes Virtuais da pós-graduação em Ciência de Dados e Inteligência Artificial Aplicada ao Mercado Financeiro – PUC Minas. O trabalho consistiu na criação de um chatbot que simula um atendimento bancário simples e foi desenvolvido em duas etapas principais. Primeiro foi implementado um chatbot baseado em regras, utilizando menus e fluxos conversacionais pré-definidos. Depois o projeto foi evoluído para utilizar técnicas de Processamento de Linguagem Natural (NLP), permitindo interpretar frases livres digitadas pelo usuário.

Na versão baseada em regras, o chatbot funciona por meio de um menu inicial que direciona o usuário para três fluxos principais: consulta de saldo da conta, bloqueio de cartão e solicitação de aumento de limite. Cada fluxo foi construído utilizando perguntas fechadas e caminhos bem definidos, garantindo que o usuário consiga navegar facilmente pelo atendimento. Também foram implementados mecanismos de fallback para lidar com entradas inválidas e comandos auxiliares como “menu”, “voltar” e “sair”, permitindo reiniciar ou encerrar a conversa de forma adequada.

Na etapa seguinte o chatbot foi evoluído para interpretar linguagem natural utilizando um modelo simples de classificação de texto. Para isso foi utilizado Python com a biblioteca scikit-learn, aplicando um pipeline de processamento de linguagem que transforma a frase digitada pelo usuário em vetores de texto utilizando TF-IDF e depois utiliza um classificador para identificar a intenção da mensagem. Dessa forma o usuário pode escrever frases como “quero ver meu saldo”, “perdi meu cartão” ou “preciso aumentar meu limite”, e o chatbot consegue identificar automaticamente qual fluxo deve ser executado.

Foram definidas três intenções principais para o modelo de NLP: CONSULTAR_SALDO, BLOQUEAR_CARTAO e AUMENTAR_LIMITE. Cada intenção possui várias frases de treinamento armazenadas em um dataset utilizado para treinar o classificador. Quando o usuário envia uma mensagem, o modelo calcula a probabilidade de cada intenção e retorna a mais provável junto com o nível de confiança da classificação. Caso a confiança seja baixa ou a frase não esteja relacionada ao domínio do chatbot, o sistema ativa um mecanismo de fallback informando que não conseguiu entender a solicitação.

O projeto foi implementado em Python e utiliza principalmente as bibliotecas scikit-learn e ferramentas básicas de processamento de texto. A estrutura do projeto inclui o chatbot baseado em regras desenvolvido na etapa anterior, o chatbot com NLP e o dataset utilizado para treinamento do modelo. Para executar o projeto basta instalar a dependência necessária com pip install scikit-learn e executar o arquivo principal do chatbot com python chatbot_tp3_nlp.py.

Este projeto tem finalidade acadêmica e utiliza apenas dados simulados para demonstrar como um chatbot pode ser desenvolvido e evoluído ao longo de diferentes etapas, começando com uma abordagem baseada em regras e posteriormente incorporando técnicas de processamento de linguagem natural para melhorar a experiência de interação com o usuário.
